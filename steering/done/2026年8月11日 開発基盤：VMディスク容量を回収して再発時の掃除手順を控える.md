- When: 2026年8月11日
- Where: exe.dev VM `/dev/root`（20G）
- Who: Feel + Claude
- What: `/dev/root` 使用率 100%（残 59M）→ 69%（残 5.9G）まで回収

    - `.vscode-server/data/logs`（314M）

## 原因（パレート分析）

削除前 `/home/exedev` 11G の上位 5個で **76%** を占有。共通パターンは1つ：

**開発ツールが自動アップデート時に古い版を掃除しない。**

- VSCode server: `lru.json` に記録があるのは 5個だが実物は 12個 → 7個は追跡外の孤児
- Claude CLI: `2.1.132〜2.1.150` の 5世代 + 空の 2.1.227（今日の updater 失敗残骸）
- Claude Code 拡張: `2.1.145` と `2.1.153` が並存
- npm cache: 使用予定のないパッケージも保持

## 掃除手順（再発時に再利用）

現行版だけ残して古い版を削除する。**現行版の特定を必ず先に行う**こと。

### 1. 現状把握

```bash

sudo du -h -d 1 / 2>/dev/null | sort -hr | head -10

```
