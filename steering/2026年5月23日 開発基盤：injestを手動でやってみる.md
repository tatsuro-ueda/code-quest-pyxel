## 1) Journey（どこへ行くか）

> 補足：深層的目的 script なしで Karpathy 流の ingest ループが回る最小形を自分たちの repo で掴む
> 補足：やらないこと 最初から自動 ingest tool や大きな schema 設計まで広げない

1. 前提条件
   1. 💦 `llm-wiki/` はいま `raw/` だけが残る raw-only 状態である
   2. 💦 今回の最初の source は Karpathy の LLM Wiki gist を使う前提で進める
   3. 💦 gist が言う ingest は raw 追加だけで終わらず、wiki・index・concept/entity・log 更新まで含む

2. Before
   1. 💦 raw に source を置いたあとの手動フローが repo にまだ無い
   2. 💦 1本の source が wiki 全体のどこへ波及するかをまだ試せていない
   3. ❌ 迷う

3. After
   1. 💦 新しい source を raw に置いたあと、LLM と話しながら wiki 更新を進める流れが 1 本通る
   2. ✅ summary、index、entity/concept、log まで含めた手動 ingest の最小導線が tasknote に残る
   3. ❤️ 安心

4. 例外
   1. 最初の source だけでは entity/concept 更新が 10〜15 ページまで増えない可能性がある
   2. gist の要約だけでは足りなければ source を読み直して再要約してよい

5. 境界条件
   1. 今回は手動 ingest の試運転であり、自動化 script は作らない
   2. 必要なら `llm-wiki/wiki/` は最小ページだけ手で戻す

6. 委任度
   1. 🟢 全体として CC 単独で下書きできる：source と flow はすでに指定されている
   2. 🟢 CCのみで可：tasknote 起票、raw source 追加案、手動フロー整理
   3. 🔴 人の判断：trial 後にどこまで恒久構造へ昇格させるかは未確定

### 変更範囲

- やること:
  - raw collection に新しい source を追加する
  - source を読みながら wiki page を手動で更新する

- やらないこと:
  - ingest 自動化 script の追加
  - 最初から完全な schema 設計を決め切ること

### 検証

- 検証コマンド:
  - `find llm-wiki -maxdepth 4 -type f | sort`
  - `git diff --stat`
- 成功条件:
  - raw source と手動更新した wiki page 群が repo 上で確認できる
  - どの page を更新したか tasknote に残る
- 未実施時の扱い:
  - source 追加や wiki 更新が未実施なら ingest trial 完了扱いにしない
