# Story Concepts Summary

## TL;DR

この source は、Block Quest Pyxel の story spine を `見えてしまう者は、世界の歪みを無視できない` に固定する。中心は `違和感 -> 反発 -> 孤独 -> 自覚 -> 選択` の zone arc、`主人公と同質だが壊れた未来` としての Glitch、`世界樹 / 通信塔` の象徴、そして `戦闘ログそのものが哲学を語る` という設計である。

## 主要トピック

- 役割は押しつけでなく、見えてしまう人が引き受けるものとして描く
- RPG の敵、戦闘、回復、成長、敗北の意味を `理解` と `自己受容` へ再定義する
- 各 zone を主人公の内面変化アークへ対応づける
- 世界樹と通信塔を `考えていい` と `考えるな` の象徴として置く
- 戦闘ログを最も重要なテキスト面として扱う

## 深い洞察

- mechanic と story が分離せず、戦闘の言葉づかい自体がテーマ表現になる
- boss を排除対象でなく mirror として置くことで、 defeat / victory の倫理が変わる
- landmark は map design、narrative guidance、theme expression の接点になる

## 注意点

- 新要素追加より既存素材の組み合わせを優先する制約が強い
- 物語の強さは dialogue や battle log で担保されるため、 text quality の依存度が高い
