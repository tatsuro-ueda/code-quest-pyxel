# UX Policy

## TL;DR

この source は「UX Policy」を扱う markdown で、主要トピックは 1. 子どもが読める表記を優先する、2. いま選んでいる操作だけを見せる、3. 押した実感を返す、4. 危険操作は無言で通さない です。子どもが「いま何が起きているか」を迷わず受け取れ、親が補助するときも主体性を奪わないための UI / 表記 / 操作方針。
