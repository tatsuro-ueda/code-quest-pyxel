# 2026年5月23日 開発基盤：カルパシー資料1本で手動取り込みを試す Summary Draft

## summary

この note は、Karpathy 資料 1 本で raw から summary、index、ingest log、related page まで回る手動 ingest の done 条件を定めた child note です。page 数ではなく、どの器を更新したかで初回 trial を判定する構造にしています。

## key_points

- raw source、summary、master index、ingest log、related page 2 件以上を初回 ingest の done 条件にした。
- auto script や taxonomy 細分化を急がず、`areas` をまず関連ページ置き場に使うと決めた。
- related page が 2 件に届かない時は、保留理由を log に残せばよいとした。

## important_quotes

- "`page 数ではなく更新した器で done 判定`"
- "`related page は 2 件以上か、保留理由`"
