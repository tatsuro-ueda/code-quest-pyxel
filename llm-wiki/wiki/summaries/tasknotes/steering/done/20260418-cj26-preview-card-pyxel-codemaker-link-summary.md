# 2026年4月18日 CJ26 開発版カードから Pyxel Code Maker を開けるようにする Summary Draft

## summary

この tasknote は、preview zip を落としたあとに検索で公式 URL を探させず、開発版カードからそのまま Pyxel Code Maker へ進めるようにする話をまとめた記録です。中心は、download だけでは `Code Maker に持っていく` 体験が selector 上で途中で切れてしまうため、まずは `開発版` カードにだけ公式入口を足して round-trip を閉じるべきだと整理したことでした。

## key_points

- preview 用 `code-maker-preview.zip` は落とせるようになっても、その次の公式入口が selector には無かった。
- そのため利用者は zip を落としたあとに別タブで検索して公式 URL を探す必要があった。
- この状態を `Code Maker に持っていく` 体験が途中で切れていると整理した。
- `CJ26` の round-trip 価値を最後まで届けるには、selector 上の導線も必要だと固定した。
- scope は広げず、まずは `開発版` カードにだけ公式入口を足す方針に絞った。
- この note は、download 後の次の一歩をどう案内するかに焦点を当てた。

## important_quotes

- "別タブで検索して公式URLを探す必要がある"
- "Code Maker に持っていく"
- "開発版 カードにだけ公式入口を足す"

## open_questions

- `Code Maker に持っていく` 流れは、selector 上でどこまで閉じているべきか。
- 公式 URL への導線は、`開発版` と `本番` のどちらまで同じ形で持つべきか。
