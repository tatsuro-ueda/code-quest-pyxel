# UX Checklist

`docs/ux-policy.md` の初版を、変更前に確認しやすい yes / no 形式へ落とした checklist。

## 子ども向け表記

- [ ] せりふ、メニュー、エラー文言はひらがな中心になっている
- [ ] 漢字を使う場合、文脈だけで意味が取れる
- [ ] 内部用語や英語を子ども向け表示へそのまま出していない

## 画面の分かりやすさ

- [ ] いま選んでいる操作だけが見えている
- [ ] 前のメッセージや別 UI が、今の選択 UI に重なっていない
- [ ] ガイドは次の一歩を示すが、答えを全部は出していない

## 押した実感

- [ ] ボタンや選択肢に押した実感が返る
- [ ] 複雑なフェードより、即時で分かる切替を優先している
- [ ] エラー時の文言が、子どもに次の行動を伝える

## 危険操作

- [ ] 保存上書きや削除など、戻しにくい操作に確認がある
- [ ] Code Maker を子どもの正式編集面として扱っている
- [ ] AI 都合で `.pyxres` や子どもの変更を勝手に置き換えていない

## Web 共有

- [ ] URL を開いたらすぐ遊べる
- [ ] スマホで全画面プレイできる
- [ ] 共有導線の変更は、公開物相当まで確認している

## 親子の役割

- [ ] 親は補助役であり、何を直すかの決定権を奪っていない
- [ ] 子どもが「自分たちのゲーム」と言える流れを壊していない
